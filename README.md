# CodSoft Task 2 - Phishing Awareness Program

## Overview

This project was completed as part of my CodSoft Cyber Security Internship.

The Phishing Awareness Program is an educational presentation designed to help users understand phishing attacks, recognize common warning signs, and follow safe cybersecurity practices.

## Objectives

- Understand what phishing is and how it works
- Learn about common phishing techniques
- Identify suspicious emails and messages
- Recognize fake login pages and fraudulent URLs
- Understand the role of social engineering in phishing
- Learn practical ways to prevent phishing attacks
- Test knowledge through a short cybersecurity awareness quiz

## Topics Covered

- Introduction to Phishing
- How Phishing Attacks Work
- Common Phishing Techniques
- Phishing Email Red Flags
- Fake Login Pages and Fraudulent Websites
- Social Engineering
- Realistic Phishing Examples
- Phishing Prevention and Security Tips
- Awareness Quiz

## Project Type

Cybersecurity Awareness / Educational Presentation

## File Included

- `Phishing_Awareness_Presentation.pptx` - Complete phishing awareness presentation

## Key Security Practices

Users should:

- Verify the sender before responding
- Check website domains carefully
- Avoid clicking suspicious links
- Never share passwords, OTPs, or PINs
- Be cautious of urgent or threatening messages
- Verify unexpected requests through official channels
- Enable multi-factor authentication where available
- Report suspicious emails and messages

## Conclusion

This project demonstrates the importance of cybersecurity awareness in preventing phishing attacks. By learning to recognize suspicious messages, links, websites, and social engineering tactics, users can reduce the risk of credential theft and other security incidents.
